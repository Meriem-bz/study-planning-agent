# Stakeholders

| Stakeholder | Type | Why they matter | Main need | Main concern |
|---|---|---|---|---|
| Student | Primary | Primary user | Useful and realistic weekly plan | Wrong priorities or lost privacy |
| Instructor | Secondary | Creates course expectations | Students receive accurate task information | Agent invents deadlines or instructions |
| Department / project owner | Secondary | Sponsors or evaluates the system | Useful project with clear scope | Cost, quality and compliance |
| IT / Security | Secondary | Maintains access and integrations | Safe authentication and data handling | Credential leakage or excessive permissions |
| Calendar / data service | Secondary | External dependency | Well-formed requests and allowed access | Rate limits, outage, permission scope |

## Raw needs

- Student wants urgent deadlines visible.
- Student does not want the agent to edit the calendar automatically.
- Instructor wants course deadlines represented accurately.
- IT wants minimum permissions for external services.
